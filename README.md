# BSTVC Organization Website

## English

[BSTVC official website](https://bayesianstvc.github.io/) is the official portal for the BSTVC brand.

BSTVC (Bayesian Spatiotemporally Varying Coefficients) is a Bayesian methodology and product ecosystem for understanding spatiotemporal heterogeneity. This repository contains the source code, page resources, and published content of the official website.

### Three Core Capabilities

1. **Local Spatiotemporal Interpretability**  
   Reveal where, when, and why local effects vary.
2. **Global Spatiotemporal Interpretability**  
   Identify the key factors shaping spatiotemporal variation.
3. **Dynamic Spatiotemporal Prediction**  
   Project outcomes as spatiotemporal conditions change.

### Products

The website currently presents four ways to work with the BSTVC ecosystem.

1. [BSTVC-R](https://github.com/bayesianstvc/BSTVC-R) — Reproducible modeling in R.
2. [BSTVC-Desktop](https://bayesianstvc.github.io/BSTVC-Desktop/) — No-code Windows analysis.
3. [BSTVC-Shiny](https://github.com/bayesianstvc/BSTVC-Shiny) — Interactive web exploration.
4. [BSTVC-Monitor](https://github.com/bayesianstvc/BSTVC-Monitor) — Local resource diagnostics.

Product repositories and release pages are the sources of truth for current versions, platforms, installers, checksums, requirements, and installation notes.

# BSTVC 组织官网

## 中文

[BSTVC 官网](https://bayesianstvc.github.io/) 是 BSTVC 品牌的官方门户网站。

BSTVC（Bayesian Spatiotemporally Varying Coefficients，贝叶斯时空变系数）是一个面向时空异质性解释的贝叶斯方法与产品体系。本仓库保存 BSTVC 官方网站的源代码、页面资源和发布内容。

### 三项核心功能

1. **局部时空可解释性**  
   揭示局部效应在何地、何时以及为何发生变化。
2. **全局时空可解释性**  
   识别塑造时空变化的关键因素。
3. **动态时空预测**  
   在时空条件变化时，对结果进行预测。

### 产品

官网当前展示 BSTVC 体系的四种工作方式。

1. [BSTVC-R](https://github.com/bayesianstvc/BSTVC-R) — 可复现的 R 建模包。
2. [BSTVC-Desktop](https://bayesianstvc.github.io/BSTVC-Desktop/) — Windows 无代码分析工具。
3. [BSTVC-Shiny](https://github.com/bayesianstvc/BSTVC-Shiny) — 交互式 Web 探索应用。
4. [BSTVC-Monitor](https://github.com/bayesianstvc/BSTVC-Monitor) — 本地资源诊断工具。

产品仓库和发布页面是当前版本、平台、安装包、校验和、系统要求及安装说明的来源。
